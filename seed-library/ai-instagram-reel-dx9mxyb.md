## Summary
This video demonstrates how to use Referro, a design reference tool, alongside Claude Code to gather inspiration from popular apps and websites without manually screenshotting them. By connecting Referro via MCP (Model Context Protocol) to Claude Code, you can request design elements from specific companies and have them applied to your project.
