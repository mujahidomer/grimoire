## Summary
This video demonstrates how to use Referro, a design inspiration tool that aggregates popular app and website interfaces, to find reference designs for building pages in Cloud Code. By connecting Referro via MCP to Cloud Code, you can search for design patterns by page type and use them as visual references without manually screenshotting or copying entire designs.

## Key Takeaways
- **keyBenefit:** Get design inspiration from real, popular apps without needing to manually screenshot or visit multiple websites, and use natural language to request specific design patterns through MCP integration
- **basicWorkflow:**
  - Visit referro.design
  - Search for a page type or design element you want to reference
  - Highlight the design or element you like
  - Copy it to your clipboard
  - Paste it into Cloud Code as a visual reference
- **whatReferroIs:** A tool that scrapes and organizes designs from popular apps and websites, searchable by page type (account pages, billing pages, homepages, dashboards) and UI/UX elements
- **importantCaveat:** Use Referro as a reference tool for design inspiration, not as a way to copy and paste entire websites or apps
- **advancedMCPWorkflow:**
  - Connect Referro to Cloud Code using MCP
  - Type a natural language request in Cloud Code (e.g., 'mimic this page the way Spotify made it')
  - Cloud Code accesses the entire Referro database
  - Referro pulls matching design elements based on your request
  - Design elements are applied to your project with your company style
